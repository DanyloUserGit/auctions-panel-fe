# auctions-panel-fe

Фронтенд панелі віддаленої роботи з аукціонами (React + Vite + MUI).

```bash
cp .env.example .env   # VITE_API_URL, ключ Turnstile, STUN/TURN
npm ci
npm run dev            # розробка
npm run build          # продакшн-збірка в dist/
```

Розгортання: [`../docs/deployment.md`](../docs/deployment.md).
